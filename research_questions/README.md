# Research Questions

This directory preserves questions, hunches, possible connections, and unresolved observations before they become claims.

## Status values

- `OPEN`
- `SEARCHING`
- `PARTIAL`
- `ANSWERED`
- `MYTH_IDENTIFIED`
- `NEEDS_PRIMARY_SOURCE`
- `CLOSED`

## Required fields

- Question ID
- Date raised
- Exact question
- Why it matters
- Related record IDs
- Search terms and spelling variants
- Sources checked
- Current status
- Current answer or uncertainty
- Next action

Questions are not evidence. They may generate canonical records, negative-evidence records, source conflicts, or no record at all.
