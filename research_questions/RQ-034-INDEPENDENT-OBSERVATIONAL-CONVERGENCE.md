  central_problem: >
    Two or more reports may share unusual details because they describe the same event,
    the same ordinary environmental cause, a shared cultural template, investigator
    prompting, later narrative harmonization, or a genuinely independent unresolved
    phenomenon. The project needs a reproducible method for distinguishing these cases.

  core_questions:
    - Were the original statements recorded before witnesses or investigators cross-exposed them?
    - Are the shared features specific or generic?
    - Do the reports derive from one hidden publication, rumor, investigator, or media source?
    - Could all witnesses have observed one ordinary object or environmental event?
    - What details conflict, disappear, or appear only in later retellings?
    - Which reports have precise time, location, viewing geometry, and environmental records?
    - Does instrument or sensor evidence form an independent source chain?
    - How should uncertainty be represented without a misleading single score?

  do_not_treat_as_proof:
    - number of repetitions without source-chain analysis
    - geographic distance by itself
    - shared labels such as UFO, UAP, portal, entity, or craft
    - generic similarities such as light, disc, voice, underground place, or missing time
    - witness sincerity as proof of interpretation
    - investigator agreement
    - lack of an immediate mundane identification
    - a high component profile as a probability of extraordinary origin
    - modern terminology projected backward
    - sensor claims without the original sensor record

    The project applies the Observation Report and Convergence Cluster schemas to at

    A repeatable workflow distinguishes high-value independent convergence from same-event

## Existing foundation

The repository already required:

- primary-source provenance;
- separate event, documentation, publication, and popularization dates;
- transmission and contamination checks;
- low weight for broad similarity;
- greater priority for specific combinations.

RQ-034 adds the missing operational objects:

```text
one report
        = OBSERVATION_REPORT

several reports under comparison
        = CONVERGENCE_CLUSTER
```

## First pilot selection

The first pilot should remain historical and bounded so that primary statements, dates, environmental conditions, and later corrections can be recovered.

Recommended pilot family:

```text
nineteenth- and early-twentieth-century polar phantom-land observations
```

The pilot is not intended to prove a single transhistorical phenomenon. It will test whether the schemas can distinguish:

- one observation later corrected;
- atmospheric-optical explanations;
- shared scientific expectations;
- independent parallel observation structures;
- later narrative simplification.
