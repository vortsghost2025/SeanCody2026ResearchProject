```text

        = proto-Dulce base / surveillance / alien-conflict seed
        = full Grey/Reptilian command hierarchy not yet demonstrated
```

This is a **search order**, not an evidentiary ranking.

## Required hierarchy classifications

```text
FULL
= all three decisive elements occur explicitly in one dated artifact

PARTIAL-AB
= reptilian/Draconian authority + Grey subordination, but no base/treaty/genetic context

PARTIAL-BC
= Grey role + base/treaty/genetic context, but no reptilian/Draconian authority

PARTIAL-AC
= reptilian/Draconian authority + base/treaty/genetic context, but no explicit Grey subordination

NOT-MET
= artifact exists but does not contain the required hierarchy

UNKNOWN
= artifact unavailable, undated, or known only through a later summary
```

## Source-status classifications

- `CONFIRMED_PRIMARY`
- `PRIMARY_ITEM_METADATA_ONLY`
- `CONTEMPORARY_REFERENCE`
- `SECONDARY_SUMMARY`
- `LATE_COMPILATION`
- `UNVERIFIED_CLAIM`

A candidate cannot receive `FULL` from a secondary summary alone.

## Useful negative result

Session 038 succeeds even when it finds:

```text
no single origin artifact
        ↓
several partial traditions
        ↓
later compilation fuses them
        ↓
origin is backdated in web summaries
```

That outcome should be classified as `MULTIPLE_PARALLEL_FUSIONS` or `LATE_COMPILATION_MISTAKEN_FOR_ORIGIN`, not as research failure.
