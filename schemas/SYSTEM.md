# Canonical Cross-Domain System Schema

A system groups connected timelines, domains, motifs, entities, claims, places, traditions, and transmission paths without assuming that all components share one origin.

```yaml
SYSTEM:
  id: SYSTEM-underground-world-001
  canonical_name: Underground World and Hidden Civilization System
  description: >
    Cross-domain system tracing subterranean-world concepts across mythology,
    religion, literature, occultism, archaeology, ufology, politics, media,
    geography, and technology.
  domains:
    - mythology
    - religion
    - literature
    - occultism
    - archaeology
    - ufology
    - media
    - geography
  traditions:
    - culture_or_framework: Greek
      figures_or_concepts: [Hades, Tartarus]
    - culture_or_framework: Indic
      figures_or_concepts: [Naga realms, Patala]
    - culture_or_framework: modern pulp
      figures_or_concepts: [Vril-ya, Deros, Teros]
  components:
    entities: []
    records: []
    motifs: []
    sources: []
    research_questions: []
  chronology:
    claimed_time: []
    first_documentation: []
    surviving_manuscripts: []
    translations: []
    reinterpretations: []
    amplification_events: []
  transformations:
    - sacred or cosmological underworld
    - hidden advanced civilization
    - occult initiatory realm
    - pulp technological civilization
    - UFO underground base
  geographic_movement: []
  relationship_status:
    allowed:
      - DOCUMENTED_TRANSMISSION
      - PLAUSIBLE_DIFFUSION
      - INDEPENDENT_PARALLEL
      - RETROACTIVE_FUSION
      - UNRESOLVED
  added_session: SESSION_022
  last_reviewed: 2026-07-13
```

## Rule

Systems connect evidence across domains while preserving separate cultural lineages. Similarity is not collapsed into common origin.
