# Sean & Cody 2026 Research Project

A source-traceable research atlas for studying how myths, theories, testimony, fiction, historical events, and modern internet narratives develop and connect across time and geography.

## Core question

This project does **not** begin by deciding whether a claim is true or false. It asks:

- **What** was claimed or described?
- **Who** recorded, repeated, translated, or popularized it?
- **When** did it first appear in a traceable source?
- **Where** did it originate?
- **Why** might it have appeared in that culture or historical period?
- **How** did it spread, change, merge, or become reinterpreted?

Evidence strength remains a separate field so documented history, mythology, fiction, testimony, speculation, and fabricated material are never silently mixed.

## Evidence classes

- **A — Confirmed source/event:** the publication, artifact, archive, broadcast, expedition, or documented tradition exists.
- **B — Well-supported interpretation:** substantial support remains, with some uncertainty.
- **C — Plausible but unverified:** possible, but not established.
- **D — Testimonial or narrative:** personal account, oral claim, contactee statement, or unsupported retelling.
- **E — Contradicted or highly implausible:** conflicts with authenticated records, chronology, geography, logistics, or physical evidence.
